# 2.1 武将重绘方向

目标不是继续调亮原图，而是按参考图 `wujiang/曹操.png` 和已确认样张 `docs/art-references/approved-general-style-v2.1.png` 的方向重绘整套武将卡。

当前 42 张可用武将图已按 2.1 方向批量落地到 `public/assets/generals/`。批次源图、裁切预览和总览校验图保存在 `output/general-art-v2.1-generated-batches/`。

武将名保留生成图原生卡面，不再额外贴名牌。个别生成字形不准时，优先保持卡面整体融合感。

## 总体风格

- 清爽、明亮、干净、通透。
- 保留高级三国杀卡牌质感，不做廉价扁平风。
- 日光环境优先，减少黑压阴影和脏灰纹理。
- 人物五官、衣纹、盔甲、技能文字区都要清晰。
- 背景保留场景和势力信息，但空气感更强，不喧宾夺主。
- 画面看起来应是重新绘制，不是简单调亮、调对比或磨皮。

## 不能撞脸

每个武将必须有独立人物 DNA：

- 年龄段不同：少年、青年、壮年、中年、老将不能混成同一张脸。
- 脸型不同：方脸、长脸、圆脸、瘦削脸、粗犷脸、贵族脸要区分。
- 体型不同：谋士、君主、猛将、弓将、女将、医者不共用同一身形。
- 发型胡须不同：长髯、短须、无须、发冠、散发、束发要按角色安排。
- 气质不同：仁君、枭雄、隐忍谋士、猛将、舞姬、医者、诗人都要有明显差异。
- 场景符号不同：宫廷、战场、江东水岸、山道、书房、药庐、军帐不能全是同一背景。

生成提示词由脚本输出：

```bash
npm run art:generals:redraw-prompts
```

输出目录：

```text
output/general-art-v2.1-redraw/
```

其中每名武将都有独立提示词和检查项。
